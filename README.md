# Shiroha.Leafy

テキストベース(DOMベースではない)のHTMLプロセッサ。

テンプレートエンジン、静的サイトジェネレータ

HTMLで書かれたページの雛型とHTMLで書かれた文書を合成してWebページにする。複数段重ねることもできるし、本文とサイドバーなど、内容側のHTMLをどこに挿入するかも指定できる。

部分HTMLをカスタム要素として定義して文書内に挿入することもできる。

- HTMLドキュメントのマージ
    - `<head>`要素のマージ、オーバーライド
    - `<body>`要素、`<main>`要素、`<section>`要素へのコンテンツ挿入。
- 部品の再利用
