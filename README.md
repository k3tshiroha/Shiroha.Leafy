# Shiroha.Leafy

DOMベースではなく構文木ベースのHTMLプロセッサ。HTMLやXML（のような言語）で書かれた文書を処理する。

## やりたいこと

静的サイトジェネレータとして使うことを想定する。動的なHTML生成パイプラインの部品としても使えるようにしたい。

HTMLで書かれたページの外枠と、HTMLで書かれた文書を合成して、一つのWebページにする。複数段重ねることもできるし、本文とサイドバーなど、内容側のHTMLをどこに挿入するかも指定できる。

部分HTMLをカスタム要素として定義して文書内に挿入することもできる。

- 要素の検索・抽出
- HTMLドキュメントのマージ
    - `<head>`要素のマージ、オーバーライド
    - `<body>`要素、`<main>`要素、`<section>`要素へのコンテンツ挿入。
- 部品の再利用
